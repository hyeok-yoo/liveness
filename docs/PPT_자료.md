# PPT 생성용 자료 (AI 입력용)

> **용도**: 발표 PPT를 AI로 생성할 때 넣는 내용 자료. **디자인은 별도 `design.md`를 따르며, 이 문서는 디자인을 지시하지 않는다.**
> 학교 제출용 정식 보고서는 `docs/탐구보고서.md`. 여기는 슬라이드별 핵심 메시지·불릿만 rough하게 담는다.

## 메타
- 주제: 2D 웹캠만으로 사진·영상 위장 공격을 막는 얼굴 라이브니스 탐지 (rPPG 심박 + 무아레)
- 발표자: 고3 2인 팀
- 분량: 약 12~14 슬라이드 / 10~12분
- 구성: 서론(동기·목적) → 본론(이론·설계·결과) → 결론
- 톤: 고등학생 탐구. 자신감 있되 성능 과장 금지.
- 관통 메시지: **"신호의 세기가 아니라, 얼굴과 배경의 차이를 본다."**

---

## [서론]

**S1. 표지**
- 제목: 2D 웹캠만으로 "진짜 사람"을 가려낼 수 있을까?
- 부제: 원격 심박(rPPG) + 무아레 패턴 기반 얼굴 라이브니스 탐지 / 팀·이름·날짜

**S2. 탐구 동기**
- 얼굴로 폰 여는 게 당연해졌지만, 사진 한 장에 뚫린다면?
- 깊이/적외선 없는 2D 얼굴 인식은 인쇄 사진·화면 사진·영상 재생에 취약
- 질문: 추가 하드웨어 없이 평범한 웹캠만으로 사진과 진짜 사람을 구별할 수 있을까?

**S3. 탐구 목적**
- 추가 HW 없이 RGB 웹캠만으로 위장 공격 차단 (개념 증명)
- 심박(rPPG) + 화면 재촬영 흔적(무아레)으로 다층 방어 설계
- 시연 가능 수준 구현 + 정량 지표(FAR/FRR/ACER) 검증 + 한계 규명

---

## [본론 — 이론]

**S4. 위장 공격의 종류**
- 인쇄 사진 → 심박 없음(rPPG)
- 화면 사진 → 심박 없음 + 무아레
- 영상 재생 → 무아레
- 행동 요구(눈 깜빡임)는 녹화 영상으로 우회 → 위조 어려운 물리·생체 신호에 집중

**S5. 핵심 단서 ① rPPG (원격 심박)**
- 한 줄: "사진에는 심장이 없다."
- 심장이 뛰면 피부 혈류 변화로 색이 미세하게 바뀜 (산소포화도 측정 원리)
- 카메라 영상의 피부색 변화만으로 비접촉 심박 추정 = rPPG
- 변화량 RGB 1% 미만 → 신호처리로 추출 / 사진엔 심박 대역(42~150 BPM) 신호 없음
- (구현: POS, CHROM)

**S6. 핵심 단서 ② 무아레 패턴**
- 한 줄: "화면을 다시 찍으면 줄무늬가 생긴다."
- 디스플레이 격자 + 카메라 센서 격자 간섭 → 무아레
- "화면 재촬영물"이라는 증거 / 주파수 영역 중·고주파 에너지 증가 → 2D FFT로 측정

---

## [본론 — 설계]

**S7. 전체 구조: 다층 방어**
- 한 줄: "한 신호가 뚫려도 다음 층이 막는다."
- 흐름: 카메라(6초) → ①사전검사(조명) → ②얼굴검출/ROI(MediaPipe) → ③무아레 FFT → ④무아레 LBP+SVM(선택) → ⑤rPPG 심박 판정 → ⑥얼굴 인식
- 어느 한 층이라도 의심하면 거부(보수적 OR). 신원 매칭(⑥)은 라이브니스 통과 후 맨 마지막.

**S8. ⭐핵심 아이디어: 절대값 → 상대값** (가장 강조)
- 문제: 절대 SNR 임계값으로 판정했더니 진짜 내 얼굴이 자꾸 거부됨(false reject). 조명·카메라·거리마다 신호 세기가 들쭉날쭉. 임계값↓→사진도 통과 / 임계값↑→본인 거부.
- 통찰: rPPG 본질은 "세기"가 아니라 "맥박은 얼굴에만, 배경엔 없다".
- 수식: **margin = (얼굴 SNR) − (배경 SNR)**
  - 사진: 얼굴 ≈ 배경 → margin ≈ 0 이하
  - 실제 얼굴: 얼굴 ≫ 배경 → margin 큰 양수
  - → 환경이 바뀌어도 차이는 유지 = 강건. (프로젝트의 전환점)

**S9. 강건하게 만든 추가 설계**
- 다중 ROI 융합: 이마+양 볼 가중 합 → 노이즈 상쇄, √N배 보강
- 다중 윈도우 best-of-N: 6초를 4초 윈도우로 쪼개 가장 좋은 구간 채택 → 흔들림 무시
- best-ROI fallback: 한 부위만 강해도 통과 → 그림자/가림 대응
- 신호처리: Tarvainen 디트렌딩, Hanning+zero-padding FFT, 하모닉 SNR, 포물선 보간
- 피부 픽셀 마스킹(YCrCb): 머리카락·안경 제외 → SNR↑

**S10. 시연 안전망 & 단순화**
- decisive(기본): 사진이면 즉시 거부 — 보안 우선
- demo: rPPG 약하면 경고만 통과 — 단 사진·영상은 무아레·사전검사가 여전히 차단
- 단순화: 처음 10초+모션검사 → 6초 단축, 모션검사 제거(rPPG가 흔들림 이미 처리). "더하는 것만큼 덜어내는 것도 설계."

## [본론 — 결과]

**S11. 데모**
- 본인 → "환영합니다"(LIVE) / 사진 → "심박 신호 미감지"로 거부(+화면이면 무아레)
- 거부 사유를 수치 담긴 한국어로: "심박 신호 미감지 — 얼굴-배경 SNR −2.6 dB < 기준 +1.0 dB"

**S12. 평가 결과**
- 지표: FAR=위장 통과율(↓), FRR=본인 거부율(↓), ACER=평균
- 실제 얼굴 margin +3~+15 dB → LIVE / 사진 margin −1.2~−4.2 dB → SPOOF
- ablation: 무아레만 / rPPG만 / 전체 → 각 층 기여도 비교
- ⚠️ 소규모 2인 데이터 기반 개념 증명 — 통계 일반화엔 한계.

## [결론]

**S13. 결론**
- 다층 방어로 사진(rPPG)·영상(무아레)을 서로 다른 단서가 차단 — 단일 실패 지점 제거
- 배경 상대 margin으로 환경에 강건한 판정 — 절대값→상대값 관점 전환이 핵심
- false reject ↔ false accept 균형은 임계값 조절이 아니라 판정 관점 전환으로 풀었다.

**S14. 느낀점 · 한계 · 향후**
- 느낀점: 막히면 원리로 돌아가라 / 사용성도 설계다 / 보안 trade-off를 몸으로 배움
- 한계: 고화질 OLED 원본 영상 재생은 막기 어려움(근본 한계) / 무아레 임계값 환경 민감 / 소규모 데이터 / 수 초 캡처 필요 / 측면·저조도 취약
- 향후: 무아레 LBP+SVM 학습, OLED 재생 대응 단서, 모바일·브라우저 이식, 표본 확대

## 부록 — 예상 Q&A (발표자 노트용)

- **사진을 천천히 흔들면 심박처럼 안 보이나요?** → 얼굴·배경이 같이 움직여 같은 주파수 → margin 안 생김. 큰 움직임은 rPPG 다중 윈도우가 회피하거나 얼굴 프레임 부족으로 먼저 걸림.
- **왜 딥러닝(CNN)을 안 썼나요?** → 2인·소규모 데이터(클래스당 ~10장)라 과적합 위험. rPPG는 물리 원리 기반 룰 → 학습 데이터 불필요 + 거부 이유를 수치로 설명. (무아레는 향후 학습형 보강 설계.)
- **고화질 화면 영상 재생은?** → 무아레 약해질 수 있어 단독 의존 안 함, rPPG·사전검사 병행. 단 OLED 원본 영상 재생은 근본 한계로 정직하게 명시.
- **본인인데 거부되면?** → 상대 margin 전환+신호처리 강화로 해결. 환경 미지수일 땐 demo 모드(rPPG 거부권 빼되 사진·영상 차단 유지).
- **ROI를 왜 이마·양 볼 3곳?** → 혈류 풍부+간섭 적은 부위. 융합으로 신호↑, 부위별 심박수 일치로 가짜 신호 한 번 더 검증.
